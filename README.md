my first repository

## Star Sign Finder

`index.html` is a small, self-contained page. Enter your birthday and it shows
your star sign and a horoscope for the chosen day (today by default).

To use it, open `index.html` in any browser. Nothing needs installing.

The horoscopes are generated for fun inside the page, so no internet connection
or API key is needed. The same sign and day always give the same reading.

## Dog Park Finder

`dog-parks.html` lists every dog park within 1 km of an address you enter,
nearest first, each with a link to see it on a map.

It looks up the address and the dog parks on OpenStreetMap, so it needs an
internet connection. A park only shows up if someone has added it to
OpenStreetMap.

## Cloud Weather Guide

`clouds.html` describes the ten main cloud types in plain language. Pick the
one that matches your sky to see what weather to expect today. When the page
is opened through its claude.ai link, you can also upload a sky photo and
Claude picks the closest cloud type. Opened as a plain file, it shows the list
only.
